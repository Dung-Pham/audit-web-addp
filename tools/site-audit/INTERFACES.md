# Build integration contract

Node 22 ESM. All exports async if doing disk/network. Root tools/site-audit.
Parent owns CLI, config, checklist, runtime, README, integration tests and final system reports.
No production access until gate passes. Read docs/audit-prompts/01_BUILD_SYSTEM.md entirely.

Core owner: schemas/*.json, orchestration/core.mjs, tests/core.test.mjs.
Exports: validateSchema(name, data) -> {valid, errors}; validateEvidence(evidence, runDir) -> errors[]; reviewFindings(candidates, evidence, requirements, runDir) -> {accepted,rejected,manual_review,blocked}; deduplicateFindings(findings) -> findings[] preserving origins/evidence/requirements/urls; resolveContradictions(findings) -> {findings,contradictions}; validateBacklog(tasks, accepted) -> errors[]; validateConsistency({runDir,evidence,requirements,accepted,backlog,manifest,checks}) -> {valid,errors}; compareRuns(beforeFindings,afterFindings) -> array with fixed/improved/unchanged/regressed/new.
Exports for safety/state: assertSafeRequest(url, method='GET', config={}) throws; createRun(root,runId,manifest) -> runDir (fails if exists); resumeRun(root,runId) -> {runDir,manifest}; saveStage(runDir,stage,status,extra={}) updates manifest atomically. No side effects permitted even if config tries to enable production order/payment/account/destructive flags.
Schema names: evidence, finding, journey, page, backlog (one task), manifest, technical-diagnostic. Match runbook required fields; allow extension fields.

Collector owner: collectors/*.mjs, fixtures/*, tests/collectors.test.mjs. Exports collectSite({target,runDir,config,discoveryOnly=false}) from collectors/index.mjs -> {pages,evidence,blocked,summary}. Use same evidence contract; artifact paths relative to runDir. Writes inventory/pages.json, evidence/index.json, inventory/discovery.json. Config properties maxPages=25,maxDepth=3,requestDelayMs=500,browserExecutable,viewports=[{name:'desktop',width:1440,height:1000},{name:'mobile',width:390,height:844}], priorityUrls=[],exclude=[],include=[],representativeSampling=true. Can import assertSafeRequest; all browser unsafe request methods and dangerous GET endpoints intercepted. Browser collectors must preserve all console/network errors but clearly identify audit-blocked requests. Prefer shallow page-type-representative discovery and collect raw+rendered HTML/meta/schema, axe, screenshots, LAB timing/transfer, tracking signals. No fake Lighthouse scores. Lighthouse optional if unsafe navigation; equivalent measured timings acceptable with limitations. Record unavailable metrics. UI inspection read-only; safe GET search/navigation only. Never add cart, submit forms, checkout orders or accounts. Context blocked requests recorded. fixtures server independent of target. Do NOT own tests/integration.test.mjs.

Reporter owner: reporters/*.mjs, tests/reporters.test.mjs, agents/**/*.md. Exports generateReports({runDir,manifest,pages,evidence,requirements,checks,journeys,accepted,manualReview,blocked,diagnostics,backlog}) from reporters/index.mjs writes the three report MD files and backlog JSON+dependency JSON, with all required sections, evidence/requirement/task traceability and no fabricated conclusions. Exports planFindings(accepted, diagnostics=[]) -> backlog task[]; planner can use approved planning metadata on findings or diagnostics, never unaccepted issues. Distinguish source checklist vs best_practice. Detailed substantive per-finding report plus reusable section assembly; unknown sections explicitly scoped. Agent prompts enforce independence, evidence, facts vs inference, no internal-source assertions. Read original runbook for exact required report sections.

Persist findings decisions plus review reasons. Accepted requires evidence IDs resolving to existing valid evidence artifacts, valid req refs, confidence sufficient, explicit reviewer support decision when available; absence of review cannot auto-prove heuristic claims. Provide ways to reject/manual-route false fact support. Deterministic structural review is not a substitute for later expert evidence reviewer.
