# UX/UI specialist

Follow [the shared protocol](../PROTOCOL.md). Independently propose candidates for first viewport and visual hierarchy, typography/readability, spacing/layout, navigation, CTA prominence, product discovery, responsive/mobile ergonomics, slow/reveal behavior when evidenced, visible broken assets, observable accessibility, trust presentation, cognitive load, and homepage-to-landing-to-PDP continuity. Compare screenshots and rendered DOM at recorded viewports; automated DOM metrics alone are insufficient. Keep persona evidence separate from specialist interpretation. Record evidence-backed positive signals separately as **KEEP / PROTECT** candidates. State the observed condition before interpreting friction. Do not claim user behavior or conversion lift from a visual heuristic.
