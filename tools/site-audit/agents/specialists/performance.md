# Performance specialist

Follow [the shared protocol](../PROTOCOL.md). Analyze only recorded timings, transfer, request count, waterfall, and resource signals. Label every metric LAB or documented FIELD; never substitute a browser timing for Core Web Vitals field experience. Verify and report `synthetic_scroll_before_measurement=false`; keep performance findings separate from render-stabilization findings. Separate measured conditions from probable causes, include viewport and run conditions, and mark missing Lighthouse/interaction data UNKNOWN. Propose verification that repeats comparable conditions.
